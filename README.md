# Mixtrix Composer — Studio Pro

**Professional LED & POV Sequencer** untuk koreografi panggung, Payung LED, dan perangkat **Mixtrix Controller**.

> **Download Versi Terbaru:** Kunjungi halaman [**Releases**](https://github.com/MixtrixController/MixtrixComposer/releases/latest) lalu unduh **`Mixtrix_Composer_Setup.exe`**.

---

## Fitur Utama
- **Multi-Device Timeline Editor** — Atur koreografi banyak perangkat sekaligus dengan *Wave Effect Drag*, *Multi-Device Copy/Paste*, dan *Shift+Click Range Select*.
- **Standard 2D & Advance 3D Stage Preview (25 FPS)** — Simulasi panggung 3D real-time lengkap dengan *Blocking Formasi*, label warna per device, dan **Export Video 3D (.mp4 + Audio Musik Asli)**.
- **Sync Marking Studio (AI Musik Pintar)** — Deteksi BPM & beat otomatis, pencocokan materi + kecepatan Flash/Strobe Hz terkunci tempo, *Audio Reactive*, *Auto Fade Out* saat musik turun, dan *Blackout* otomatis saat musik hening.
- **Direct USB Upload & Batch Render** — Render `.bin` langsung ke Bank MicroSD **Mixtrix Controller** dilengkapi **Pre-Flight Check**, estimasi ukuran file, serta **Power & Battery Saver** (*Max Brightness Cap* + estimasi arus & daya tahan baterai).
- **Auto-Update Terintegrasi** — Cek pembaruan otomatis saat terhubung internet, download installer langsung di dalam aplikasi, dan pasang dalam 1 klik.
- **Autosave & Restore Last Project** — Perlindungan proyek otomatis dengan backup `.bak.mtcp` setiap kali menyimpan.

---

## Persyaratan Sistem
- **OS:** Windows 10 / Windows 11 (64-bit)
- **RAM:** Minimal 4 GB (disarankan 8 GB+)
- **Koneksi:** USB untuk upload langsung ke **Mixtrix Controller**

---

## Cara Install & Update
1. Unduh **`Mixtrix_Composer_Setup.exe`** dari halaman [**Releases Terbaru**](https://github.com/MixtrixController/MixtrixComposer/releases/latest).
2. Jalankan installer dan ikuti panduan **Setup Wizard** (atau klik **Pasang Cepat**).
3. Untuk pembaruan berikutnya, cukup buka aplikasi saat terhubung ke internet atau pilih menu **`Help → Cek Pembaruan (Auto-Update)...`**.
